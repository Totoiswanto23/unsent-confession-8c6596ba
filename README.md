One micro-confession in exactly two parts: the To: line and the line that was typed and never sent. No joke, no greeting, no explanation after it — just the habit that outlived the person, and the half-second when the thumb remembers before the head does.

## The entry

> To: Dad
> I still dial your number when something good happens, then remember, and hang up before it rings.

105 characters, two lines. The reason it stayed in drafts is felt, not stated: too late. Swap the addressee and the line breaks — only a father who is gone makes dialling, remembering, and hanging up before it rings mean anything.

## Run it

```sh
node main.ts
```

`main.ts` validates the entry (exactly two lines, a To: line naming who it was meant for, message 1–200 characters, whole entry 1–260 characters, no leading or trailing whitespace) and writes it to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`), with no trailing newline so the file is exactly the two lines.
